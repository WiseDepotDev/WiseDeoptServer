## 为什么之前是"过期文件"

2026-02-27 的核查（`tools/gen/swagger-drift.js`）发现：旧文件是**手工导出**的产物，登记 61 条路由且**全部缺少 `/api` 前缀**（如 `/auth/login`），而控制器源码实际声明 139 条带 `/api` 前缀的路由，两者仅 1 条匹配。当时已在 README 顶部标注"不得作为契约使用"。

现在该文件由运行中的服务直接导出，**与实现天然一致**；后续接口变更后应重新导出，而不是手工编辑。
